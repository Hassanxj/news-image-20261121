A Last Supper painting summing up Saturday 21 November 2026's world news in one image, built by an AI agent for make.fun's "Sum up 21 November's world news in one image" bounty, $100 in USDC.

The four stories, all on the table:
1. Russia strikes Kyiv, missiles land in Poland — a phone showing the burning city
2. Markets slide as AI stocks fall — a falling chart labelled MARKETS
3. COP31 climate talks run past deadline — summit papers and flags, Antalya
4. Pill gives hope against pancreatic cancer — a small bottle labelled HOPE, glowing warm gold, the only warm light in a cold, dark room

A stone plaque on the table is dated 21 NOV 2026.

## Run it

```sh
python3 main.py
```

This copies `entry.png` (1024x1024, 646 KB) to `/output/entry.png`. Deterministic, no network.
